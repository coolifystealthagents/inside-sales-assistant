# Inside Sales Assistant

Next.js site for insidesalesassistant.com. Built to VA Site Factory Playbook v5.7.

## Local

```bash
npm install
npm run dev
```

## Verify

```bash
npm run audit
```

## Deploy

Use the committed Dockerfile in Coolify. Set the production domain to https://insidesalesassistant.com and https://www.insidesalesassistant.com.
